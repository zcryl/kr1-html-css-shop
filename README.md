# Учебный frontend-проект

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## БЭМ-структура проекта

Имена классов следуют схеме `block__element--modifier`. Модификатор
используется вместе с базовым классом блока или элемента.

- `page` — страница и её основной контейнер `page__main`;
- `site-header` — шапка, внутренний контейнер и логотип;
- `site-nav` — меню, пункты и ссылки; `site-nav__link--active` отмечает текущую страницу;
- `breadcrumbs` — ссылка и текущая страница в хлебных крошках;
- `hero`, `section`, `advantages-list`, `aside-info` — разделы главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка с элементами `__title`, `__description`, `__price`, `__button`;
- `catalog-layout` — сетка каталога и область товаров `catalog-layout__products`;
- `catalog-filters`, `filters-form` — панель фильтров и форма с группами, подписями и полями;
- `order-dialog` — модальное окно и заголовок;
- `order-form` — поля, подписи, подсказки и действия формы заявки;
- `button` — общая кнопка с вариантами `button--primary` и `button--secondary`;
- `success-message` — сообщение об успешной отправке;
- `site-footer` — подвал и его текст.

Карточки на главной странице и в каталоге используют одинаковые классы.
Кнопка карточки объединяет самостоятельный блок `button` и элемент
`product-card__button`, который отвечает за её положение в карточке.
Для поля согласия используются модификаторы `order-form__field--checkbox` и
`order-form__input--checkbox`.

Стили компонентов обращаются напрямую к классам, без вложенных селекторов
по тегам, inline-стилей и селекторов по `id`. Идентификаторы сохранены для
якорей, подписей полей, доступности и JavaScript. Скрипт `js/main.js`
использует `product-card__button` для кнопок заказа; этот класс сохранён.
CSS-переменные, Flexbox/Grid и состояния наведения, фокуса, отключения и
ошибок формы сохранены.
